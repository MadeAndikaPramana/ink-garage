# Ink Garage Tattoo Studio — Canggu, Bali

Website for Ink Garage Tattoo Studio (tattoo, piercing, nail art and a coffee
bar in Canggu). React 19 + Vite + Tailwind v4 + react-router-dom + `motion`,
with a small GitHub-API-backed admin panel at `/admin` for managing portfolio
photos without a database. Visual style: "garage zine" — warm paper, hard
outlines, offset shadows, stickers, tape and a ticker strip; palette taken from
the studio's cobalt logo.

## Quick start

```bash
npm install
npm run dev
```

## Admin panel (`/admin`)

Requires these environment variables on the deploy target (Vercel):

- `ADMIN_PASSWORD` — shared password for the panel
- `GITHUB_TOKEN` — token with `contents:write` on this repo
- `GITHUB_USERNAME` / `REPO_NAME` — this repo's owner/name
- `GITHUB_BRANCH` — optional, defaults to `main`

The project must live at the repository root (the API reads
`src/data/portfolio.json` and writes `public/images/` at the repo root).
Each save creates one commit via the GitHub Trees API.

## Deploy

Vercel (`vercel.json`, `/api` functions). `wrangler.json` only serves static
files, so the admin API will not run on Cloudflare.

## SEO

`npm run build` prerenders every public page (`/`, `/team`, `/portfolio`,
each `/portfolio/<category>`, `/pricing`, `/book`) to real static HTML with its
own title, description and social tags (`scripts/prerender.js`,
`src/entry-server.jsx`), then the browser hydrates. Page titles/descriptions
live in each page's `useDocumentHead()` call — the prerender reads the same
values. `/admin` and `/team/:branch` stay client-only.

- **Demo mode = noindex.** While `SITE_URL` is unset, every page is built with
  `<meta name="robots" content="noindex">` so the demo (stock photos,
  unverified details) stays out of Google.
- **LAUNCH STEP: set `SITE_URL`.** When the real domain is connected, set the
  `SITE_URL` env var (e.g. `https://inkgaragecanggu.com`, no trailing slash)
  in Vercel and redeploy. That lifts the noindex and turns on
  `<link rel="canonical">` and `og:url`. **Forget this and the site never
  gets indexed.** The build log warns while it is unset.
- **Share image.** `public/og-image.jpg` (1200×630) is generated by
  `npm run og:image` from the studio photo + logo. On Vercel it is referenced
  via `VERCEL_PROJECT_PRODUCTION_URL` automatically.
- **Structured data** in `index.html` is a `TattooParlor` with address, phone
  and Instagram. It intentionally has no `aggregateRating` (Google ignores
  self-marked-up ratings). After launch add `url`, `image` and
  `openingHoursSpecification` once hours are confirmed.
- **Still to do at launch** (not in the code yet): `sitemap.xml` + a `Sitemap:`
  line in `robots.txt`, Google Search Console, and real photos replacing the
  demo ones (alt text already says "Sample … photo (demo)" for those and will
  switch to "… tattoo by <artist> at Ink Garage, Canggu" once `demo` is gone).
